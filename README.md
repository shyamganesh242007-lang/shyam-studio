# Shyam Studio

Shyam Studio is a business platform for showcasing software projects, providing live demos, selling source code, and offering custom software development services.

## Project Status

🚧 Under Development

## Features

* Project Showcase
* Project Categories
* Project Search
* Live Demo Links
* GitHub Links
* Source Code Pricing
* Service Pricing
* Admin Dashboard
* Admin Authentication
* Project CRUD
* Image Upload
* Image Crop
* Image Compression
* WebP Conversion
* Responsive Design

## Technology Stack

### Frontend

* React
* Vite
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* Supabase

### Version Control

* Git
* GitHub
